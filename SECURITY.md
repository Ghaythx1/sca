# Security Policy

## Responsible Use & Ethical Guidelines

**sca** is designed exclusively for educational purposes, network administrators, and authorized penetration testers conducting security evaluations on systems they own or have explicit written permission to test.

Scanning third-party infrastructure without prior authorization is illegal in most jurisdictions. The authors and maintainers assume no liability for misuse, collateral damage, or regulatory violations resulting from the use of this software.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| < 1.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or exploit flaw within `sca` itself:

1. **Do not** open a public GitHub issue.
2. Please submit a private advisory via [GitHub Security Advisories](https://github.com/Ghaythx1/sca/security/advisories) or contact the project maintainer directly.
3. Include detailed steps to reproduce the issue and potential mitigation suggestions.

We strive to review and address all legitimate security concerns promptly.
